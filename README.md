# 💳 Credit Card Default Risk Prediction System

## 📌 Project Overview

The **Credit Card Default Risk Prediction System** is a Machine Learning project designed to predict whether a credit card customer is likely to default on their payment.

The project analyzes customer financial and demographic information and applies machine learning techniques to identify patterns associated with credit card payment defaults.

The goal is to help financial institutions identify high-risk customers and support better credit risk management decisions.

---

## 🎯 Objectives

- Analyze customer financial and demographic information.
- Perform data cleaning and preprocessing.
- Explore important patterns and relationships in the dataset.
- Prepare numerical and categorical features for machine learning.
- Build and evaluate classification models.
- Predict whether a customer is likely to default.
- Identify important factors associated with credit card default risk.
